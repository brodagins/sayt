# База потенциальных клиентов

Простая программа для Mac, в которой можно собирать список компаний, которым
можно предложить создание сайта.

- Интерфейс на русском языке, открывается в браузере.
- Загрузка компаний из таблицы CSV.
- Хранение в базе данных (один файл `data/clients.db` на вашем компьютере).
- **Автоматическая проверка: есть у компании сайт или нет.**
- Поиск и удаление дубликатов.
- Выгрузка базы в CSV, который открывается в Excel.

Программа работает на вашем компьютере, из интернета её не видно. Ваша база
никуда не отправляется. В интернет программа выходит только при проверке сайтов:
открывает сайты компаний и, если вы подключите поиск, отправляет в поиск Яндекса
название и город компании.

**Программа ничего не придумывает.** Компании в базе — только те, что вы
загрузили или ввели. Под каждым результатом проверки написано, на чём он основан.

---

## Что лежит в папке

| Файл | Зачем он нужен |
|---|---|
| `Запустить.command` | Двойной щелчок запускает программу |
| `app.py` | Сама программа: страницы в браузере |
| `database.py` | Работа с базой данных и поиск дубликатов |
| `csv_tools.py` | Чтение CSV-файлов и выгрузка в Excel |
| `checker.py` | Проверка, есть ли у компании сайт |
| `шаблон.csv` | Пустая таблица с правильными заголовками столбцов |
| `tests/` | Автоматические проверки программы (вам они не нужны) |
| `data/` | Появится после первого запуска. Здесь хранится ваша база и настройки |

## Установка на Mac (один раз)

### Шаг 1. Скачайте программу с GitHub

1. Откройте в браузере страницу проекта на GitHub: **https://github.com/brodagins/sayt**
2. Слева вверху над списком файлов есть кнопка с названием ветки. Если там
   написано не `main`, нажмите её и выберите ветку
   `claude/client-database-app-d51yif` (пока изменения не перенесены в `main`).
3. Нажмите зелёную кнопку **Code** (справа вверху над списком файлов).
4. В открывшемся меню нажмите **Download ZIP**.
5. Откройте папку **Загрузки** (Downloads) в Finder и дважды щёлкните по скачанному
   ZIP-файлу — рядом появится обычная папка.
6. Перенесите эту папку туда, где ей удобно лежать, например в **Документы**,
   и переименуйте в `База клиентов`.

> Название папки может быть любым. Главное — не разносить файлы по разным
> местам: все файлы программы должны лежать в одной папке.

### Шаг 2. Проверьте, что на Mac есть Python

Python — это язык, на котором написана программа. На Mac он обычно уже есть
или ставится одной кнопкой.

1. Нажмите **Command + Пробел**, введите `Терминал` и нажмите **Enter**.
2. В открывшемся окне введите и нажмите **Enter**:

   ```
   python3 --version
   ```

3. Что может произойти:
   - Появилась строка вида `Python 3.9.6` (или новее) — всё готово, переходите
     к запуску.
   - Появилось окно с предложением установить «инструменты командной строки» —
     нажмите **Установить**, дождитесь окончания (несколько минут) и снова
     выполните команду из пункта 2.
   - Ничего не помогло — скачайте Python с официального сайта
     **https://www.python.org/downloads/** (большая жёлтая кнопка
     «Download Python»), откройте скачанный файл и следуйте шагам установщика.

Устанавливать что-то ещё не нужно: программа использует только то, что входит
в сам Python.

## Запуск

### Обычный способ — двойной щелчок

1. Откройте папку программы в Finder.
2. Дважды щёлкните по файлу **`Запустить.command`**.
3. Откроется окно Терминала, а через секунду — страница программы в браузере.

**При первом запуске** macOS может показать предупреждение, что файл скачан
из интернета или «от неустановленного разработчика». Тогда:

1. Нажмите **Готово** / **Отменить** в этом окне.
2. Щёлкните по `Запустить.command` **правой кнопкой мыши** (или с зажатой
   клавишей Control) и выберите **Открыть**.
3. В новом окне снова нажмите **Открыть**.

Если кнопки «Открыть» нет (новые версии macOS): откройте
**Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз —
там будет строка про `Запустить.command` и кнопка **Всё равно открыть**.

Это нужно сделать только один раз.

### Запасной способ — через Терминал

Если двойной щелчок не срабатывает:

1. Откройте **Терминал** (Command + Пробел → `Терминал` → Enter).
2. Введите `cd ` (буквы c, d и пробел), **не нажимая Enter**.
3. Перетащите мышкой папку программы из Finder в окно Терминала — путь к папке
   вставится сам.
4. Нажмите **Enter**.
5. Введите и нажмите **Enter**:

   ```
   python3 app.py
   ```

### Если браузер не открылся сам

Откройте браузер (Safari, Chrome — любой) и введите в адресной строке:

```
http://127.0.0.1:8000
```

Точный адрес программа пишет в окне Терминала.

### Как остановить программу

Закройте окно Терминала, в котором она работает (или нажмите в нём
**Control + C**). Пока окно Терминала открыто, программа работает.

## Как пользоваться

### Загрузка компаний из CSV

1. Подготовьте таблицу. Первая строка — заголовки столбцов. Проще всего взять
   файл `шаблон.csv` из папки программы: откройте его в Excel и вставьте
   свои данные под заголовки.
2. Сохраните таблицу в Excel: **Файл → Сохранить как → Формат: CSV UTF-8
   (разделитель — запятая)**. Подходит и обычный формат «CSV».
3. В программе откройте вкладку **Загрузить CSV**, выберите файл, напишите,
   откуда эти данные (например, «выгрузка из справочника, октябрь 2026»),
   и нажмите **Загрузить**.
4. Программа покажет отчёт: сколько компаний добавлено, сколько пропущено
   как дубликаты, какие столбцы распознаны.

Обязателен только столбец с названием компании. Программа понимает такие
заголовки (регистр букв не важен):

| Поле в базе | Подходящие заголовки в файле |
|---|---|
| Название компании | Название компании, Название, Компания, Наименование, Организация, Name, Company |
| Город | Город, Населенный пункт, City |
| Категория бизнеса | Категория бизнеса, Категория, Рубрика, Сфера, Вид деятельности, Отрасль, Category |
| Телефон компании | Телефон компании, Телефон, Телефоны, Тел, Phone |
| Адрес | Адрес, Address |
| Сайт | Сайт, Веб-сайт, Website, Site, URL |
| Источник данных | Источник данных, Источник, Source |
| Статус проверки | Статус проверки, Статус, Status |

Столбцы с другими заголовками программа пропустит и покажет их в отчёте.

### Проверка: есть ли у компании сайт

Откройте вкладку **Проверка сайтов** и нажмите **Проверить непроверенные**.
Программа проверит компании по очереди (несколько минут на тысячу компаний) и
поставит каждой статус. Одну компанию можно проверить кнопкой
**Проверить сайт сейчас** в её карточке (щелчок по названию компании).

Как программа решает:

1. **Сайт указан в данных** → открывает главную страницу.
   Открылась нормальная страница — «сайт есть». Домен не существует, ошибка или
   страница «домен продаётся» — «сайт не открывается».
2. **Сайт не указан** (или указана только соцсеть или справочник вроде 2ГИС) →
   ищет «название + город» в поиске Яндекса и открывает найденные сайты:
   - на сайте тот же телефон, что у компании, или адрес сайта совпадает
     с названием → «сайт есть», адрес записывается в поле «Сайт»;
   - сайт похож, но уверенности нет → «нужна повторная проверка»
     (адрес — в пояснении, проверьте сами);
   - нашлась только страница в соцсети → «только соцсети»;
   - ничего не нашлось → «сайт не найден».

Для второго пункта нужно подключить поиск Яндекса (см. ниже). Без него
компании без сайта остаются «не проверено» — программа проверит только
указанные сайты.

> Поиск может ошибаться: найти сайт тёзки или не найти сайт, который плохо
> виден в поиске. Поэтому под каждым статусом в таблице мелким шрифтом
> написано, на чём основан результат. Перед звонком важным клиентам
> стоит нажать «искать сайт» и проверить самим.

### Статусы проверки

| Статус | Что значит |
|---|---|
| сайт есть | Сайт работает (указан в данных или найден поиском и совпал с компанией) |
| сайт не найден | Сайта нет в данных и нет в первых результатах поиска Яндекса |
| только соцсети | Собственного сайта нет, есть страница в соцсети |
| сайт не открывается | Сайт указан, но не работает или на адресе страница «домен продаётся» |
| нужна повторная проверка | Найден похожий сайт, но уверенности нет — проверьте сами |
| не проверено | Проверку не запускали, или сайт не указан, а поиск не подключён |
| сайт устарел | Ставите вы сами, если сайт есть, но старый. Проверка его не меняет |

Статус можно поменять вручную прямо в таблице на вкладке **Компании**.

### Подключение поиска Яндекса (один раз)

Программа ищет сайты через **Yandex Search API** — официальный способ
отправлять запросы в поиск Яндекса из программ. Обходить капчу обычного поиска
программа не будет: это нарушает правила Яндекса.

Это **платная** услуга Yandex Cloud: одна компания — один запрос. Посмотрите
актуальные цены на странице Search API в Yandex Cloud перед тем, как проверять
большую базу. На вкладке «Проверка сайтов» программа заранее пишет, сколько
запросов понадобится.

Что нужно сделать (названия кнопок в Yandex Cloud могут немного отличаться):

1. Зайдите на **https://console.yandex.cloud** под своим Яндекс-аккаунтом и
   подключите платёжный аккаунт.
2. Откройте свой **каталог** (folder) — он создаётся автоматически, обычно
   называется `default`. Его **идентификатор** — строка вида `b1g...` —
   виден на странице каталога. Скопируйте его.
3. В каталоге создайте **сервисный аккаунт** и дайте ему роль
   `search-api.webSearch.user`.
4. Откройте этот сервисный аккаунт и создайте **API-ключ**. Скопируйте ключ
   сразу: второй раз его не покажут.
5. В программе откройте вкладку **Настройки**, вставьте ключ и идентификатор
   каталога и нажмите **Сохранить и проверить подключение**.

Подробная инструкция Яндекса:
https://yandex.cloud/ru/docs/search-api/quickstart/

Ключ хранится только на вашем компьютере, в файле `data/settings.json`.
Не пересылайте этот файл другим людям.

### Дубликаты

Похожими считаются записи, у которых совпадает хотя бы одно:

- телефон (`8 (900) 111-22-33` и `+7 900 111 22 33` — один и тот же номер);
- сайт (`http://www.site.ru/` и `site.ru` — один и тот же сайт);
- название + город + адрес (без учёта «ООО», кавычек и регистра букв).

При загрузке CSV такие записи по умолчанию не добавляются (галочку можно снять).
На вкладке **Дубликаты** можно для каждой группы выбрать, что делать:
**Объединить** (дополнить одну запись данными других), **Удалить остальные**
или отметить **Это разные компании**. Сама программа ничего не удаляет без
вашего нажатия.

### Выгрузка в Excel

Вкладка **Экспорт → Скачать всю базу для Excel**. Файл открывается в Excel
двойным щелчком. Чтобы выгрузить только часть базы (например, один город),
задайте фильтры на вкладке **Компании** и нажмите
**Скачать эти записи для Excel**.

Если в Excel все данные оказались в одном столбце, скачайте вариант
«обычный CSV» и откройте его через меню Excel **Файл → Импорт**.

### Резервная копия

Вся база — это один файл `data/clients.db` в папке программы. Закройте
программу и скопируйте этот файл (или всю папку программы) на флешку или
в облако. Чтобы восстановить базу, верните файл на место.

## Важно о данных

- Загружайте только данные, которые получены законно и с соблюдением правил
  источника (условий использования справочников, сайтов и т. п.).
- Программа не обходит защиту сайтов, капчи и ограничения поисковиков. Сайт
  компании она открывает одним запросом, как обычный браузер. Для поиска
  использует только официальный API Яндекса.
- Отсутствие сайта в исходной таблице программа не считает доказательством:
  «сайт не найден» ставится только после поиска.

## Для тех, кто будет дорабатывать программу

- Python 3.9 или новее, без сторонних библиотек.
- Запуск без автоматического открытия браузера: `python3 app.py --no-browser`.
- Автоматические проверки: `python3 -m unittest discover tests`.
